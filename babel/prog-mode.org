* treesitter
- Treesitter rapidly builds a tree of your program's structure
  - even if it's incomplete
  - even if it contains errors
  - will build the tree in parts
- It is like a DEV time compiler
  - use it to catch syntax errors
  - use it for syntax color coding

* language server
- lsp does what treesitter does and adds additional functions
  - documentation
  - project integration

** lsp-mode
- integration with Language Servers like Intelephense by default

https://github.com/emacs-lsp/lsp-mode
https://github.com/emacs-php/php-mode/wiki/LSP-Support

https://emacs-lsp.github.io/lsp-mode/tutorials/CPP-guide/

To use Corfu as your completion UI with lsp-mode, you must tell
lsp-mode to stop managing company-mode and allow Emacs's native
completion-at-point-functions (Capf) to handle the candidates.

#+begin_src emacs-lisp
(use-package lsp-mode
  ;; emacs interface to a language server
  :commands lsp
  
  :init
  ;; Tell lsp-mode not to configure company-mode automatically
  (setq lsp-completion-provider :none)
  :config
  ;; Optional: Force orderless or standard filtering on lsp completions
  (setf (alist-get 'styles (alist-get 'lsp-capf completion-category-defaults)) 
        '(orderless basic))

  ;; default is lsp kep is s-l
  (lsp-enable-which-key-integration t)
  
  :hook
  (sh-mode .        lsp-deferred)
  (c-mode  .        lsp-deferred)
  (c++-mode .       lsp-deferred)
  (lisp-mode .      lsp-deferred)
  (python-mode .    lsp-deferred)
  (python-ts-mode . lsp-deferred)
  )
#+end_src
