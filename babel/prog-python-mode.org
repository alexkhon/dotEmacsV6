* elpy
https://elpy.readthedocs.io/en/latest/introduction.html
Load elpy only in python-mode

#+begin_src emacs-lisp
  (use-package elpy
    :ensure t
    :defer t
    :init
    (advice-add 'python-mode :before 'elpy-enable))
#+end_src

** flake8
"Flake8 is a command-line tool that automates the checking
process. Instead of reading through your code manually to see if you
violated the PEP 8 guidelines, you can run Flake8 on your files, and
it will output a list of errors with line numbers"

** pep8
"PEP 8 (Python Enhancement Proposal 8) is a written document that
dictates best practices for how Python code should be formatted."

** references
https://shivdeepak.com/posts/linting-in-python/
